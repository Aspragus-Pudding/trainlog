# Workflow

1. Notes: tap the pencil on any screen (setup too). They're in Progress → Notes; a tester's go to the shared feedback sheet.
2. Changes go to Claude Code with `roadmap/ROADMAP.md` and CLAUDE.md; interaction changes are mockups first (CLAUDE.md, How to work on this).
3. Before a commit: the checks in CLAUDE.md (syntax, invariants, the injury library, simulator, phone tests, backtest).
4. A push to main deploys to GitHub Pages; phones pick it up on the next launch.
5. Testers: ALPHA.md (setup links, what their data touches) and README.md (install, first session).
