# Number audit (v1.82)

Every chart, sparkline, score and number on every screen, with one question:
what does the user do with it? If the answer was nothing, the number became a
sentence or went. If there was an answer, the number stayed and its answer is
now next to it.

| Item | Screen | Result | Why |
|---|---|---|---|
| Readiness score (0–100) and its band word | Dashboard, readiness card | kept | Tells you how long to warm up and whether anything steps up. The effect is on the same line (v1.71). |
| Joint rating against your usual (n / 3) | Dashboard, readiness card | kept | Tells you which work is held or lighter today. The effect is on the same line (v1.71). |
| Readiness and joint scales | Readiness sheet | kept | The legend that makes the two numbers above readable. |
| Days to go | Dashboard | kept | You plan around your test or target date. |
| Block and week | Dashboard and header | kept | Tells you where you are in the program. |
| Recent bests (estimated max) | Dashboard | kept | Your progress at a glance; "estimated max" is tappable for what it means. |
| Exercises and sets done | Workout, progress card | kept | Tells you how far through the session you are. |
| Weight × reps and RPE per set | Workout, set rows | kept | What you lift. |
| Last time, beside each set | Workout and preview | kept | What to beat, from the same set the suggestion is priced from. |
| Estimated session length | Workout preview | kept | Lets you plan the session against your time. |
| % of your estimated max | Workout preview | changed | Now only on main lifts, as "about 80% of 300 lb: how heavy today is against your best". On accessories it was noise. |
| Warm-up ramp loads | Set panel | kept | The weights you load for warm-ups. |
| Rest timer | Workout | kept | You rest until it runs out. |
| Typical weekly sets, three hard-looking ranges per block type | Lifts, main-lift card | changed | "Chest: about 12 sets this week in your plan; a typical range is 10–20 a week, a rough guide, not a rule." The landmarks are judgement defaults (Grade D) and shouldn't look like science. |
| Estimated max, and where it's from | Lifts, main-lift card | kept | The number your loads are priced from. |
| Estimated max over time, big number and change | Progress, goal card | kept | Whether the lift is going up. |
| "N sessions with a usable estimate" | Progress, goal card | changed | Now "Estimated max, change since Sep 15", which says what the change is measured over. |
| 3RM / 5RM / 10RM | Progress, goal card | kept | For picking a working weight. It already said so. |
| High-rep vs heavy-set gap | Progress, goal card | kept | It says which estimate to trust for loading. |
| Training max | Progress, goal card | kept | The planning number for strength blocks. It says it moves only with test sets. |
| Best set, last three sessions | Progress, goal card | kept | What you actually lifted. |
| Suggestion accuracy (% lifted as suggested, reps near, on target) | Progress | kept | Whether the app fits you. It already said it measures fit, not obedience. |
| Weekly volume chart | Progress | changed | Kept the chart and added what to read in it: a block builds, a deload drops, a sudden fall usually means missed sessions. |
| Readiness over time | Progress | changed | Kept, plus one line: falling scores are one sign behind a deload suggestion. |
| Joints over time | Progress | changed | Kept, plus one line: one that stays above your usual holds the work that loads it. |
| Notes count | Progress | kept | How many notes are still open. |
| Sets per muscle per week, sparkline | Edit program, block card | changed | Now a sentence: "About 10 sets a week per muscle in week 1, rising to 16 by week 4, then a lighter week (5)." |
| Intensity %, sparkline | Edit program, block card | removed | The generator's internal load target. There's nothing to do with it, and the sentence above covers what changes. |
| Weeks of blocks against weeks available | Edit program, dates | kept | Says whether your blocks fit the dates. |
| Weekly sets against the typical range | Week preview | kept | You add or remove sets against it. It's labelled as a typical range. |
| Strength ↔ size share (%) | Setup and Edit program | kept | You set it. The line says what it means in blocks and tests. |
| Muscle weights (direct 1.0 / indirect 0.5) | Exercise info sheet | changed | Now "main muscle (a full set)" or "helps (half a set)". |
| Sessions performed | Exercise info sheet | changed | Folded under the best estimated max: "From 12 sessions. The more heavy sets of a few reps, the steadier the estimate." |
| Smallest jump, bar weight, sled weight, rest | Exercise info sheet | kept | Settings you change. |
| Events (raw count of log lines) | Settings, your data | removed | An internal count. Working sets and sessions stay, as reassurance that the log is there. |
| Storage (KB, persistent or not) | Settings, your data | kept | "Not persistent" turns warning-coloured and means back up now. |
| Version | Settings, about | kept | For bug reports and checking an update arrived. |
| Tonnage ("lb moved") | Session summary | changed | The headline cell now shows new bests. Tonnage stays in the comparison with last time, where it means something. |
| Sets and time | Session summary | kept | How the session went against your plan. |
