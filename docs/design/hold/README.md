# Batch N Part 4: new screens (mockups, waiting for a pick)

Live app screens on demo data with the proposed screens put in place, dark and light, 390 px. The engine for all of them shipped in v1.101–v1.102; nothing is on screen until a pick.

1. **Where are you training today?**
   - **1A (my pick):** chips on the Train summary card, the last place already picked, and what changes said in one line. Most days it's the same place, so no extra tap.
   - **1B:** a sheet after Start, one button per place, with how many exercises change.
2. **How long do you have?**
   - **2A:** a second row of chips beside the places.
   - **2B (my pick):** a sheet behind a "How long do you have?" link, saying what each length leaves out. It's needed now and then, so it stays off the card.
3. **A paired set card**
   - **3A:** one card for the pair, with A and B chips and which one is next.
   - **3B (my pick):** the two existing cards, linked by a rail and a line saying which one is next. It reuses the card and panel you already know, and the rest timer already runs after the pair.
4. **Hold on Today:** the week as muscle targets with ticks, where the plan waits, and Back to my program.
5. **The hold offer** (with 1, 2 or 3 days) **and the first-session-back line** in Today's plan.
6. **A ladder exercise on the set card:** "Step 6 of 11 · Push-ups ▸" and the move-up proposal. The design is in `docs/home-import.md`.
